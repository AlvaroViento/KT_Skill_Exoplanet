# 外部证据与中国平台检索

## 中国语境的默认含义

“中国语境”首先指中国真实用户的生活情境、说法、行为、替代方案和服务体验。验证这些内容时，优先搜索中国用户实际使用的平台，不要先用政策文件、宏观报告或国外社区替代真人证据。

只有法规、标准、统计规模、技术能力和高风险边界，才优先使用中国官方、标准或学术来源。

## 按主张选择来源

| 要验证的主张 | 首选来源 | 不能单独证明 |
|---|---|---|
| 这类人是否存在、是否反复遇到该问题 | 小红书、抖音/快手、微博、知乎、B 站、豆瓣、贴吧等独立用户内容 | 代表性、市场规模、因果 |
| 用户当前如何解决、为何仍不满意 | 用户帖子与评论、应用商店评论、黑猫投诉、电商评价、本地生活/旅游平台 | 行业整体结论 |
| 某产品或服务是否真有该能力 | 产品官方文档、应用商店说明、真实用户反馈交叉核验 | 法定合规性 |
| 问题规模、人口或行业数据 | 国家/地方统计、主管部门、可靠研究 | 具体用户体验 |
| 法规、标准、监管要求 | 现行法律法规、主管部门、国家/行业/地方标准 | 用户是否愿意使用 |
| 理论与技术边界 | 原始论文、大学/研究机构、官方技术文档 | 当前纸面已表达 |

案例图、竞赛图、营销稿和公众号转载只能用于发现关键词或表达形式，不能单独证明现实成立。

## 中国平台路由

- **小红书**：生活方式、消费与服务体验、照护、健康、育儿、学习、旅行、职场等第一人称场景。
- **抖音 / 快手**：下沉市场、线下劳动、老人、家庭、商户和公共服务的短视频场景及评论。
- **微博**：突发事件、公共议题、投诉和时间敏感讨论。
- **知乎**：较长的经历叙述、职业/专业解释和方案比较；注意回答者选择偏差。
- **B 站**：年轻用户、学习与数码产品、操作过程、教程及评论反馈。
- **豆瓣 / 贴吧**：兴趣群体、长期困扰、疾病/照护/生活阶段等长尾社区。
- **应用商店、淘宝/京东评价**：真实使用障碍、退货原因、维护成本和替代方案。
- **黑猫投诉、12315 公开信息**：服务失败、责任归属和高频投诉线索。
- **大众点评、高德/百度地图评论、携程/马蜂窝**：线下空间、到店服务、旅游和本地行为。

按议题选择两种以上不同机制的平台，不要求每次搜全平台。例如“独居老人线上问诊”可组合小红书/抖音的家庭经历、应用商店评论和知乎的长叙述。

## 查询改写

先把设计术语改写成用户会说的话，再搜索平台：

1. 对象的自称、家属称呼、旧称和口语别名。
2. 具体动作、失败结果、抱怨句和现有替代方案。
3. 城市层级、城乡、年龄段或职业等必要限定。
4. 同时搜索支持和反例，避免只找证明方案的内容。

示例：

- `小红书 异地子女 给独居老人线上挂号 不会操作`
- `抖音 老人 手机挂号 子女帮忙 评论`
- `知乎 给父母远程挂号 经历`
- `site:xiaohongshu.com "给父母挂号"`
- `site:weibo.com 独居老人 线上问诊`
- `应用商店 老年人 挂号 难用 评论`

平台内部搜索可用时优先使用；否则用“平台名 + 口语查询”或 `site:` 检索并打开原帖。搜索摘要只能作为线索，不能代替可核对内容。

## 真人快速检测

把规格中的“3 分钟找到 5 个小红书用户”实现为中国平台优先、必要时跨平台的最低现实锚点：

1. 找到至少 5 个相互独立的真实个体或账号。
2. 优先来自中国平台，且至少覆盖 2 个独立平台或内容机制。
3. 观察是否重复出现相似情境、行为、约束或替代方案。
4. 排除品牌软文、营销矩阵、搬运、同一事件的重复传播和 AI 批量内容。
5. 每个案例只保存一句摘要、平台、日期和链接，不大量引用原帖。
6. 只据此判断“对象可发现”和“行为模式有线索”；不要据此证明代表性、因果或市场规模。

平台需要登录、反爬、内容删除或搜索结果不足时，扩展到其他中国平台，并把结论降为 `not_verified`。不能把“平台上没搜到”写成“现实中不存在”。

## 官方与学术来源的有限职责

- 法规与政策：全国人大、中国政府网、司法部及主管部门。
- 标准：国家标准全文公开系统、全国标准信息公共服务平台及主管部门现行标准。
- 统计：国家统计局、地方统计和主管部门公开数据。
- 医疗、金融、未成年人、隐私、公共安全等高风险边界：对应监管部门、现行法律和原始研究。
- 技术能力：产品官方技术文档、原始论文和可靠复现证据。

核对发布日期、实施状态、适用地区和版本；地方规定不得外推。官方数据可以说明规模或边界，但不能替代用户原话、实际行为和服务体验。

## 事实结论

- `supported`：多个适合该主张类型的独立来源支持。
- `partially_supported`：现象成立，但规模、对象范围或因果表述过强。
- `conflicted`：可靠来源或不同平台群体之间存在冲突。
- `unsupported`：关键主张与可靠证据明显冲突。
- `not_verified`：检索不足，禁止假装已证实。

报告只呈现会改变判断的证据，并明确来源类型。外部证据不得写入作者的 `VisibleEvidence`，中国平台案例也不等于纸面已经完成用户研究。
