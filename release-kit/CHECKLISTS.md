# 快题方案逻辑检查：使用清单

本文件是对外 PDF 和手机长图的唯一文字源稿。发布前不要分别手改导出版本。

## 安装清单

- [ ] 下载与当前版本一致的安装包。
- [ ] 运行 README 中的 Marketplace 与 Plugin 安装命令。
- [ ] 确认安装来源为 `exoplanet-skills`。
- [ ] 新开一个 Codex 会话。
- [ ] 使用 `$quick-sketch-logic-review` 发起一次测试。

## 输入准备清单

- [ ] 提供题目或一句话背景。
- [ ] 提供当前 Idea、草图或成图，不必为了使用 Skill 临时补全。
- [ ] 说明希望检查 Idea 还是复盘成图。
- [ ] 有考试方向、院校要求或剩余时间时一并说明。
- [ ] 不先让 AI 生成大量新功能，以免掩盖原方案问题。

## 阅读结果清单

- [ ] 方案复述是否符合原意，若不符先纠正。
- [ ] 优先处理 `fatal` 或 `major`，不要先改措辞细节。
- [ ] 检查“依据”来自当前材料还是外部资料。
- [ ] 选择一个最小修改立即落实。
- [ ] 修改后再次提交，不要求一轮解决全部问题。

## 成图复盘清单

- [ ] 现实中成立的内容，图面是否也让阅卷人看见。
- [ ] 无法辨认的内容是否被误判为没有。
- [ ] 阅读路径是否清楚呈现“问题 → 对象 → 策略 → 实现 → 结果”。
- [ ] 最值得重画的区域是否先于装饰性优化。
- [ ] 外部检索结果是否被错误当作图面证据。
